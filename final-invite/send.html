4Send emails via Google Apps Script

This sends real emails from your Gmail account (skylarmcr24@gmail.com) using Google's free daily quota. No cost, no third-party service.

One-time setup (5 minutes):
  1. Go to script.google.com and click New project.
  2. Delete the sample code, then click Copy Apps Script code below and paste into the editor.
  3. Click the disk icon to save (name it "Sweet 16 Invites").
  4. In the toolbar, choose function previewFirstInvite and click Run. First run will ask permission — Review permissions → Advanced → Go to Sweet 16 Invites (unsafe) → Allow. This lets the script send emails from your Gmail.
  5. Open the Execution log (bottom) to see the preview email — make sure it looks right.
  6. When happy, choose function sendAllInvites and click Run — sends to every guest with an email.
Note: Guests without an email address are skipped by the script. For those (or anyone you'd rather text), see the clean SMS link below.
