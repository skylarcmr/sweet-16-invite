# Simone's Sweet 16 — Save the Date

Interactive envelope invitation site for Simone's Sweet 16 birthday party.

**Event:** August 8, 2026 — One Night in Paris

## Features

- Animated envelope with wax seal — click to open
- 16 mixed-color balloons burst on open (pink, gold, black, magenta)
- 3D card flip with RSVP form
- Submissions flow directly to Google Forms / Sheets
- Mobile responsive, no dependencies, single HTML file

## Deploy

Host `index.html` anywhere static — GitHub Pages, Netlify, Vercel, etc.

## RSVP Responses

Responses land in the linked Google Sheet automatically. No API keys or server needed.
